# FileReadWrite

## Чтение и запись файлов

Программа читает содержимое одного текстового файла и записывает его в другой.

## Как работает программа

1. Получает названия двух файлов через аргументы командной строки.
2. Открывает первый файл для чтения.
3. Открывает второй файл для записи.
4. Посимвольно считывает содержимое первого файла и записывает его во второй.
5. Закрывает оба файла.

## Как запустить программу

При запуске необходимо передать два аргумента:

- "input.txt" — файл, из которого читаются данные.
- "output.txt" — файл, в который записываются данные.

## Пример аргументов

input.txt output.txt

Если второй файл не существует, программа создаст его автоматически.
